# Agent Speech Check plugin

The `asc` skill for Claude Code and Codex. It teaches an agent to use `asc`, a CLI that connects
to the NVDA screen reader, records what NVDA says and presses keys, so the agent can check what a
blind user hears in a Windows or web app: labels, focus order, live regions and keyboard
navigation.

The skill needs the `asc` CLI on PATH. See the
[main README](https://github.com/nibarAhmed/agent-speech-check#install) to install it.
